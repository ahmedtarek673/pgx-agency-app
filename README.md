# PGX Agency Mobile App

🚀 A premium React Native/Expo application for digital agency management.

## Features

- **Auth**: Firebase Authentication (Email/Google).
- **Dashboard**: Real-time project tracking and agency services.
- **UI/UX**: Custom glassmorphism effects and modern design.
- **Notifications**: Expo Push Notifications integration.

## Technologies

- **Frontend**: Expo, React Native, TypeScript, Expo Router.
- **Backend**: Firebase Firestore, Storage, and Functions.
- **Styling**: NativeWind / Tailwind CSS.

## Getting Started

1. Clone the repository.
2. Install dependencies: `npm install`
3. Run with Expo: `npx expo start`
